# QuizCraft

QuizCraft — небольшое веб-приложение для подготовки к тестам. Оно превращает обычный текстовый тест в интерактивный тест с кликабельными вариантами ответов.

## Возможности

- импорт вопросов из `.TXT` и `.DOCX`;
- вставка текста теста прямо в приложение;
- автоматическое распознавание вопросов и вариантов ответа;
- отметка правильного ответа через `(+)` в конце варианта;
- кликабельный интерфейс с подсветкой правильного и неправильного ответа;
- работа над ошибками после каждых пяти обычных вопросов;
- повторная ошибка уменьшает итоговый балл на один;
- возврат в главное меню и повторное прохождение теста.

## Формат теста

```text
1. Какая функция выводит текст в Python?
A) input()
B) print() (+)
C) output()
D) show()

2. Какой тип хранит текст?
A) int
B) float
C) str (+)
D) bool
```

Метка `(+)` используется только при создании теста и автоматически удаляется из отображаемого варианта.

## Запуск

Откройте файл `dist/index.html` в браузере. Для DOCX нужен доступ к интернету, чтобы загрузить модуль чтения документов.

## Технологии

Приложение работает как статическая HTML-страница на чистом HTML, CSS и JavaScript.
